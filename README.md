# Roast My Gallery

Roast My Gallery analyzes photo-library habits on the device and turns the resulting summary into a playful roast or a psychological reading. Photos stay on the phone; only summary statistics are sent for the generated result.

- On-device photo analysis
- Playful roast and insight modes
- Shareable story cards
- Privacy-conscious processing

[Download on the App Store](https://apps.apple.com/us/app/roast-my-gallery/id6791121107)

## Source availability

This repository is a product showcase. The application source code is private.
